# Cantinho da Leitura

Projeto simples de biblioteca virtual feito com HTML, CSS e JavaScript.

## Abrir o site

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Páginas

- `index.html`: início.
- `livros.html`: catálogo e busca.
- `gerenciar.html`: adicionar e remover livros.
- `relatorio.html`: lista e total de livros salvos.
- `conta.html`: formulários de cadastro e login.

## O que explicar na apresentação

- O HTML organiza o conteúdo das páginas.
- O CSS define cores, espaços e adaptação para celular.
- `localStorage.setItem` salva os dados e `localStorage.getItem` lê os dados.
- O JavaScript cria elementos da página com `document.createElement`.
- Eventos fazem a busca, o cadastro e os botões funcionarem.

Os livros começam com quatro exemplos e ficam no LocalStorage do navegador. O cadastro guarda nome e e-mail. Login é apenas uma demonstração: as senhas não são verificadas nem salvas. Para isso ser seguro de verdade, seria necessário um servidor.
